# Cámara en todos los buscadores

Un archivo por pantalla. En cada pantalla: abrir el archivo → Ctrl+A → Ctrl+C →
clic en una parte vacía de la pantalla → Ctrl+V. Aparece el botón negro 📷 dentro del buscador.

| Archivo | Pantalla | Buscador |
|---|---|---|
| 1_Camara_Descarte.txt | Descarte | código del libro |
| 2_Camara_Descarte_masiva.txt | Descarte masiva | lista de códigos (suma una línea por lectura) |
| 3_Camara_Prestamo.txt | Préstamo | usuario (QR de la cédula) y libros |
| 4_Camara_Devolucion.txt | Devolución | lista de códigos (suma una línea por lectura) |
| 5_Camara_Morosos.txt | Morosos | buscador (QR de la cédula → RUT) |
| 6_Camara_Inventario.txt | Inventario | código del libro |

Si Power Apps no lo acepta: Insertar → Lector de código de barras → Ctrl+C sobre el control →
pegar ese texto en el chat para fijar la versión exacta.
